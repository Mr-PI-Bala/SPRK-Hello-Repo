# AGENTS.md

## Cursor Cloud specific instructions

### What this repo is

SPRK-Hello-Repo is a collection of eight independent browser missions under `missions/`, each with a vanilla HTML/JS/CSS frontend and a Python 3 stdlib HTTP backend (`server.py`). There is no database, Docker, or formal Python packaging.

### Dependencies (already handled by VM update script)

- **Node.js ≥ 18** and **npm** at repo root (`package.json`) for Playwright only.
- **Python 3** stdlib only for mission servers (no `requirements.txt`).

### Python command on Linux

Mission helpers spawn `python server.py` by default. Cloud/Linux VMs often have only `python3`. Export before starting servers or running Playwright:

```bash
export PYTHON=python3
```

### Running a mission (manual dev)

```bash
cd missions/01-ReactionRace-nP   # example
python3 server.py
```

Open the URL printed in the terminal (ReactionRace uses port **8000**). Other missions use ports **8002–8008** (see each folder’s `server.py` or `tests/helpers/start-mission-server.js`).

For classroom/LAN testing, use `python3 server.py --host 0.0.0.0 --port <port>` (see `docs/SPRK_Classroom_Network_Test_Guide.md`).

Use a named **tmux** session for long-running backends so they survive after the shell exits.

### Automated tests (Playwright)

See `README.md` § “Direct Playwright Testing” for the full matrix.

**Linux / Cloud Agent note:** `npm test` and `npm run test:*` invoke `tests/helpers/run-playwright.js`, which shells out to Windows `cmd.exe` and `playwright.cmd`. On Linux, run Playwright directly instead:

```bash
export PYTHON=python3
export SPRK_MISSION=reactionrace
export PLAYWRIGHT_BASE_URL=http://127.0.0.1:8000
npx playwright test tests/reactionrace.spec.js --config=tests/playwright.config.js
```

`tests/playwright.config.js` starts the correct mission backend via `webServer` (`node helpers/start-mission-server.js` from the `tests/` directory). Swap `SPRK_MISSION`, `PLAYWRIGHT_BASE_URL`, and the spec file for other missions (`snakegame` → 8002, `pingpong` → 8003, etc.; keys listed in `tests/helpers/start-mission-server.js`).

There is **no ESLint/Prettier** in this repo; baseline validation is Playwright-only.

### Test mode URL

Mission UI tests often use `/?test=1` for deterministic hooks (`window.__sprkTest`). Manual exploration can use the normal `/` URL.

### Generated artifacts

Playwright writes under `tests/artifacts/`. Baseline HTML/JSON for the Baseline Status tab is generated by `tests/helpers/write-baseline-status.js` after a full `run-playwright.js` run (Windows-oriented).
