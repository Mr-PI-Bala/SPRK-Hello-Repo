    Try Changing One Thing

    Starter changes

    • Change the button text in src/app.js. (Hint: button text is set in setButton(label, state); start with the "Tap Now!" call inside startRound().)
    • Change the colors in src/styles.css. (Hint: the named color variables are at the top; try --go, --wait, or --accent.)
    • Change the default player name in src/app.js. (Hint: look for let playerName = "Maya-SPRK"; near the top.)

    Logic challenges

    • Make the wait shorter or longer. (Hint: in startRound(), change the random delay formula.)
    • Change what counts as a safe player name. (Hint: in saveNameButton's click handler, change the fallback name or add a minimum length check.)
    • Show only the top 10 scores. (Hint: in server.py, change MAX_SCORES; in renderScores(), look at how the list is drawn.)

    Level-up challenges

    • Add a team name beside each player. (Hint: add a new input in index.html, read it in app.js, then include it in the score sent to server.py.)
    • Penalize early taps instead of just resetting. (Hint: change handleEarlyTap() so it sends a slow score or shows a strike count.)
    • Add a classroom round reset message. (Hint: after clearSharedScores(), update both setMessage(...) and setScoreboardStatus(...).)
