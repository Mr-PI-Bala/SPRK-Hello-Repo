SoccerMatch

A real shared soccer field where players from multiple devices join the same live match and play together.

WASD Player

Move with W A S D, turn with Z/X, kick with Space.

Arrow Player

Move with arrow keys, turn with PageUp/PageDown, kick with Enter.

How It Plays

  • Each device can add up to two local players.
  • Touch / one phone: use two devices on the same class link (one WASD join, one Arrow join) or keyboards at the host — not all keys fit on one touchscreen. See docs/SPRK_Touch_Control_Guide.md.
  • Players choose home or away before joining.
  • Turning accelerates while held, so stronger facing control leads to stronger kicks.
  • Any device on the same host link sees the same live field.
