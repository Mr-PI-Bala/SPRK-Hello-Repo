# Mission 07: SoccerScore
SoccerScore is a team scoreboard and event tracker for sports or classroom games.

## Mission Goal
Build a shared scoreboard that tracks teams, scores, timestamps, and game events.

## Mode
`nP`: many players.

## Play It
Open the scoreboard and record a sample score event.

## Change It
Change team names, sport type, event labels, or scoreboard colors.

## Show It
Run the changed version and show the updated scoreboard.

## Level It Up
Add multiple sports, player stats, period tracking, or a shared spectator display.
