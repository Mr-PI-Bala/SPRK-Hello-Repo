# Mission 04: FlashCards
FlashCards is a school-useful mission for math, vocabulary, science, history, or any subject practice.

## Mission Goal
Build a browser flash-card tool that asks questions, checks answers, and tracks progress.

## Mode
`1P-nP`: starts as one player and can grow into shared classroom mode.

## Play It
Try one card deck and answer a few questions.

## Change It
Add a new card, change the subject, update feedback text, or adjust scoring.

## Show It
Run the changed version and show the new card or rule.

## Level It Up
Add deck selection, team practice, timed rounds, or shared class question sets.
