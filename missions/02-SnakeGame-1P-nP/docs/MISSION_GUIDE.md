# Mission 02: SnakeGame
SnakeGame starts as a solo browser game and can later grow into shared scores or classroom leaderboard mode.

## Mission Goal
Build a snake game where the player moves through a grid, collects points, and avoids collisions.

## Mode
`1P-nP`: starts as one player and can grow into many-player mode.

## Play It
Play one round and understand how movement, score, and game-over work.

## Change It
Change the snake color, speed, board size, food color, or score message.

## Show It
Run the changed version and show the visible difference.

## Level It Up
Add levels, a high-score list, shared classroom scores, or custom obstacles.
