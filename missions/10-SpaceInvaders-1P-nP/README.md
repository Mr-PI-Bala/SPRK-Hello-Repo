# Mission 10 Quick Start: Space Invaders

Run the mission backend from this folder:

```bash
python server.py
```

On Linux/macOS or Cursor Cloud, use:

```bash
python3 server.py
```

Open the browser link printed by the terminal. The mission uses port `8010`.

Controls:

- Move: `A/D` or left/right arrows
- Fire: `Space` or click the canvas
- Shift to 3D rail: `Shift` or **Dimension Shift**
- Enter FPS: `F` or **FPS Dive**
